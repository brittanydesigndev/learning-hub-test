## Purpose

Use this to record a decision on an application that's been reviewed and is complete.

## Steps

<Walkthrough doneTitle="Decision recorded">

1. **Open the application from Ready for decision.** In [Screening system], go to [Decision queue].

2. **Compare the results to the criteria.** Use the current [screening criteria document].

3. **Choose the outcome.** Select Approve, Conditionally approve or Decline.

4. **Add a decision note.** Write one or two sentences explaining the outcome for anyone who opens the file later.

5. **Send the decision.** Select [Send decision] so the applicant and the leasing agent are notified.

</Walkthrough>
