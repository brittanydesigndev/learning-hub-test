## Purpose

Use this when a new application lands in your queue and needs to be checked before a decision is made.

## Before you start

- You can access the application queue in [Screening system]
- You know the current [screening criteria document]

## Steps

<Walkthrough doneTitle="Application reviewed" doneMessage="The application is complete and ready for a decision. Next, see Making a screening decision.">

1. **Open the application.** In [Screening system], go to [Queue name] and select the oldest application first.

2. **Check that every applicant is listed.** Each adult who will live in the unit needs their own application.

3. **Confirm required documents are attached.** Look for [Document 1], [Document 2] and [Document 3].

4. **Flag anything missing.** Use the [Request info] action so the applicant gets an automatic message listing what's needed.

5. **Move it to Ready for decision.** Once everything is in, change the status so it appears in the decision queue.

</Walkthrough>

## Tips and exceptions

<Aside type="caution" title="Don't decide on an incomplete file">
If anything is missing, request it first. A decision made on partial information may need to be redone.
</Aside>
